## 📌 Project Overview

This simulator provides a side-by-side analysis of how different scheduling strategies affect process lifecycle. It focuses on the trade-off between **fairness** (Round Robin) and **efficiency** (SRTF).

### Algorithms Included:

1.  **Round Robin (RR):** A preemptive algorithm that assigns a fixed time unit (quantum) to each process in a circular queue.
2.  **Shortest Remaining Time First (SRTF):** The preemptive version of SJF, where the process with the smallest remaining execution time is prioritized.

## 📊 Comparison Logic & Metrics

The application uses the following standard OS formulas to ensure mathematical accuracy:

| Metric                    | Formula                                  |
| :------------------------ | :--------------------------------------- |
| **Turnaround Time (TAT)** | $Completion\ Time - Arrival\ Time$       |
| **Waiting Time (WT)**     | $Turnaround\ Time - Burst\ Time$         |
| **Response Time (RT)**    | $First\ Execution\ Time - Arrival\ Time$ |

### The Fairness vs. Efficiency Trade-off

- **SRTF** aims to minimize the average waiting time, but may lead to **starvation** for processes with long burst times.
- **Round Robin** prevents starvation by ensuring every process gets CPU time, though its efficiency is dependent on the **Time Quantum** ($q$).

## 🧪 Test Scenarios

To validate the simulator, the following cases are included in the documentation:

1.  **Standard Workload:** Mixed arrival and burst times.
2.  **Preemption Test:** Short processes arriving during the execution of a long process (demonstrates SRTF preemption).
3.  **Quantum Sensitivity:** Testing RR with very small vs. very large quantum.
